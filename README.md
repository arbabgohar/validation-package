# Qaabil validation package

Markdown is the working source for this validation package.

- `validation/` contains the validation plan, specifications, risk assessment, test documents, and traceability matrix.
- `compliance/` contains compliance control matrices.
- `procedures/` contains controlled quality procedures.
- `planning/` contains uncontrolled planning notes.
- `issued/` is reserved for signed, issued PDFs. Signed PDFs should be retained there and not edited as working source.

See `register.md` for the controlled document register and `docs-import-report.md` for the source inventory and consistency audit.
